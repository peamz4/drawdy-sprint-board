# Changelog

## 0.1.0 — 2026-10-27

First version.

- A sprint board on the canvas with Backlog, To do, In progress, Testing and Done columns. Drag cards between columns to change their status.
- Tickets with keys (`LAOR-001`), type, priority, story points, description and assignee.
- A panel with the active sprint, its progress, and Sprint, Backlog and Releases tabs.
- Filters: search, assignee, only my issues, type and priority, plus **Show on board** to select the matches on the canvas.
- **Complete sprint** files the Done tickets in a version-log frame below the board, carries unfinished work to the next sprint or back to the backlog, and starts the next sprint with a bumped version name.
- **Turn selection into tickets** imports existing sticky notes and cards, keeping their keys.
